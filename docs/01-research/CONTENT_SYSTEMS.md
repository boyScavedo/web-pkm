# Content Systems Research

## Content pipeline (creator workflow)

```
IDEA → RESEARCH → VALIDATION → OUTLINE → SCRIPT → RECORDING →
EDITING → THUMBNAIL/TITLE → REVIEW → PUBLISHED → ANALYTICS → REPURPOSING
```

## Key principles

1. **Content feeds from PKM knowledge.** Don't duplicate — reference.
2. **One idea can become many outputs.** A long-form video becomes a short,
   a blog post, a social thread, a course module.
3. **Post-publication review is mandatory.** What worked? What failed?
4. **Analytics are snapshots, not streams.** Store point-in-time data since
   external APIs change.

## What we build (Phase 13)

- Content items linked to notes, projects, and assets
- Pipeline stage tracking
- Content calendar (date-based view)
- Repurposing relationships (content item → derived items)
- Performance notes (manual or API-fetched snapshots)

## What we don't build

- Direct social media API integrations (fragile, high-maintenance)
- Automated publishing pipelines (manual publish + URL recording)
- Real-time analytics dashboards (periodic snapshots suffice)
